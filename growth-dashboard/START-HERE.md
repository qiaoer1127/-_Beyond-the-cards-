# 开始使用个人成长台

## 最简单的方式

1. 下载 `index.html` 文件：https://raw.githubusercontent.com/qiaoer1127/-_Beyond-the-cards-/main/growth-dashboard/index.html
2. 在电脑或手机的浏览器中打开下载的 HTML 文件。
3. 填写人生方向、添加 1–3 个 90 天目标，然后每天记录。
4. 到「数据与隐私」导出 JSON 备份。

## 重要提醒

- 数据保存在打开页面的浏览器本地存储中，不会自动同步到其他设备。
- 本地文件模式的存储行为会因浏览器而异；建议固定使用同一设备和浏览器，并定期导出备份。
- GitHub Pages 的自动部署目前需要先在仓库的 Settings → Pages 中启用 GitHub Actions 发布源。启用后，工作流会尝试部署成长台。
