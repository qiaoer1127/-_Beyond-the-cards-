# 个人成长台 Personal Growth OS

> 这是一套帮助自己把想法变成行动的轻量系统。目标不是每天满分，而是更清楚地生活。

## 使用方式

从 `index.html` 打开成长台。每天花 5–10 分钟记录，周末用 15 分钟复盘。建议先专注 90 天，不要一次改变所有事。

## 系统模块

1. **北极星 / 人生方向**：自由度、事业与财富、身体与精力、自我认知、关系、行动力。
2. **90 天目标**：每个目标需要一个结果指标、每周行动和最低可执行版本。
3. **每日记录**：今日最重要的 1 件事、3 个小行动、能量与情绪、一个观察。
4. **每周复盘**：本周推进、卡点、学到什么、下周要停止 / 继续 / 开始什么。
5. **行动清单**：下一步、预计时间、状态，避免把目标停留在愿望层面。

## 使用原则

- 用趋势代替完美主义。漏记一天不等于失败。
- 只追踪能帮助决策的少数指标。
- 让习惯适配现实生活，而不是反过来惩罚自己。
- 人生方向是指南针，不是必须遵守的判决书。

## 隐私提醒

请勿把密码、银行卡号码、身份证号码、医疗隐私或其他高敏感信息写入公开仓库。公开仓库中的内容可能被任何人查看。
