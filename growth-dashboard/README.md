# 个人成长台 Personal Growth OS

把人生方向拆成具体行动。不是每天满分，而是每周都有一点可见的推进。

## 打开成长台
打开 [`index.html`](./index.html)，可以直接在浏览器体验。

## 系统模块
- **人生方向**：自由度、事业与财富、身体与精力、自我认知、关系、行动力。
- **90 天目标**：定义可观察结果、每周行动、最低可执行版本和进度。
- **每日行动**：最重要的一件事、三项推进、能量和个人观察。
- **行动清单**：把想法转换为可执行的下一步。
- **每周复盘**：推进、卡点、学习与下一周调整。
- **导入 / 导出**：以 JSON 备份或迁移本地记录。

## 90 天路线图
查看 [`90-day-roadmap.md`](./90-day-roadmap.md)。

## 如何开始
1. 写下你希望逐渐建立的生活样貌。
2. 选择最多 3 个主线目标，并为每个目标定义清楚结果。
3. 每天花 5–10 分钟记录，疲惫时允许只做最低版本。
4. 每周用 15 分钟复盘，不给自己打人格分数，只调整系统。

## 隐私与限制
当前版本通过浏览器 `localStorage` 保存记录，只在当前浏览器环境可见，不会自动同步到其他设备。清除浏览器数据可能导致记录丢失，请定期使用「导出成长数据」备份。此仓库公开时，网页源码可被任何人查看，但浏览器本地记录不包含在仓库文件中。不要输入密码、身份证号码、银行卡资料或其他高敏感信息。
